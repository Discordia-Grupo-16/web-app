# web-app

Aplicación web de gestión (Frontend).

## Requisitos

- Node.js 18+
- npm 9+

## Setup

### Instalar dependencias:

```bash
npm install
```

### Crear variable de entorno:

```bash
cp .env.example .env
```

Modificar .env con la IP y puerto del backend.

### Ejecutar la aplicación:
Levantar la app en desarrollo:

```bash
npm run dev
```
